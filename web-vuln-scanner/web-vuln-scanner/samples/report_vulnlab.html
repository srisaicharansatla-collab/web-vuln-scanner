Not testable remotely

  • A04:2021 Insecure Design: Design flaws and business-logic abuse need understanding of intended behaviour; a generic scanner cannot judge them.
  • A09:2021 Security Logging and Monitoring Failures: Logging, alerting and incident response happen server-side and are invisible to a remote, read-only client. Review log configuration and alert rules manually.
  • A10:2021 Server-Side Request Forgery: SSRF needs an out-of-band callback server or a harmful internal target to confirm safely; this tool does not send such payloads.

Limitations

  • Static HTML crawler: JavaScript-rendered single-page apps (e.g. Juice Shop) expose few links/forms.
  • Only GET parameters and GET forms are fuzzed by default (POST needs --allow-post).
  • No authentication, so everything behind a login is out of scope.
  • Blind/time-based SQLi, DOM-based XSS, IDOR and business-logic flaws are not detected.
  • Signature-based detection can miss custom error pages and may flag documentation pages that quote error text.
